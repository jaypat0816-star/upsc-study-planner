# UPSC Study Planner

A simple and beginner-friendly study planner for UPSC Civil Services Examination aspirants.

## Features

- Daily study goals
- GS subject-wise planning
- Current affairs tracking
- Revision schedule
- Mock test tracking

## Purpose

This project aims to help UPSC aspirants organize their preparation and track their learning progress.
